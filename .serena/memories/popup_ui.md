Compoviz workspace naming and destructive confirmation flows use the typed promise-based `PopupProvider`/`usePopup` API in `src/components/ui/Popup.tsx`; native runtime `prompt()`/`confirm()` calls should not be reintroduced. The provider is mounted in the app shell and shared test renderer. Compose `resetProject()` is an unconditional `void` state action; user confirmation belongs in action handlers. In `VisualBuilder`, React Flow node deletion must be confirmed in `onBeforeDelete` so cancellation occurs before controlled canvas state is removed; `onNodesDelete` performs mutation only after approval. Resource starter controls in `BuilderToolbar` are buttons so keyboard initiation and popup focus restoration work.
